# TaskFlow - Dynamic Task Management

A clean and modern Todo application built with Vanilla JavaScript. This project focuses on DOM manipulation, state tracking, and responsive UI design without the use of external frameworks.

## 🚀 Features
* **Task Management:** Add, complete, and delete tasks instantly.
* **Real-Time Analytics:** Automatic counters for "Total Tasks" and "Completed Tasks."
* **Persistent Logic:** Designed with a focus on efficient array methods and event handling.
* **Responsive UI:** Styled with modern CSS for a smooth experience on all devices.

## 🛠 Tech Stack
* **HTML5:** Semantic structure.
* **CSS3:** Custom layouts and modern styling (Flexbox/Grid).
* **JavaScript (ES6+):** Logic, event listeners, and dynamic DOM updates.

## 🧠 What I Learned
Through this project, I strengthened my understanding of:
1. **DOM Manipulation:** How to create, select, and remove elements using JavaScript.
2. **Event Delegation:** Efficiently managing events for a list of items.
3. **Data Filtering:** Calculating the number of completed vs. active tasks dynamically.
